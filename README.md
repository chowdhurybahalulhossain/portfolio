# Bahalul Hossain Chowdhury — 3D Digital Portfolio & Resume

A personal 3D digital portfolio and resume website built with **React 19**, **TypeScript**, **Vite**, **Tailwind CSS v4**, **Three.js WebGL**, and **Framer Motion**.

---

## ✨ Highlights

- **Accurate Single Source of Truth**: 100% of the content is derived directly from Bahalul Hossain Chowdhury's official resume and portrait photo. No fabricated statistics, testimonials, or placeholder names.
- **Cinematic Dark 3D Environment**: Interactive WebGL particle constellation and floating geometric wireframe sculptures (Icosahedron, Torus Knot, Octahedron) that smoothly respond to cursor motion and scroll parallax.
- **Interactive 3D Photo Tilt Card**: Featuring Bahalul's professional portrait with cursor-tracking perspective tilt, dynamic glass glare, ambient back-glow aura, and depth badge layers.
- **Bento Grid About Section**: Highlights background at IUBAT (BCSE CGPA 3.10) & Gazipur Metropolitan College (GPA 5.00), professional focus, Python expansion, support experience, and collegiate leadership.
- **Experience Timeline**: Detailed timeline of 7 months software support engineering at **3S Softtech Limited** and client engagement at **SkyTech Limited**.
- **Interactive Project Showcase**:
  - **LinkUp**: Real-time chat application with Node.js, Express, Socket.io, PostgreSQL, bcrypt authentication, and real-time WebSocket event handling.
  - **PlugNPlay**: Full-stack MVC e-commerce platform with normalized schema, JWT authentication, RBAC authorization, admin panel, and Stripe payment integration.
  - Interactive **Architecture Inspection Modal** for deep-diving into database design and system patterns.
- **Technical Skills Matrix**: Filterable category matrix (Languages, Backend, Frontend, Databases, Tools, Core Concepts) without arbitrary percentage bars.
- **Education, Certifications & Leadership**: Academic degrees, Creative IT certifications (Frontend, SQL, Graphics Design), and Cultural Club Senior Vice Presidency.
- **Direct Contact & Verified Resume Download**: One-click download for `Bahalul_Hossain_Chowdhury_Resume.pdf`, one-click copy for email and phone, and message dispatch with confetti feedback.

## 🚀 Running the Project from D: Drive

```bash
# 1. Open terminal and navigate directly to your portfolio directory
cd "D:\Utshob as a SE\Repository\portfolio"

# 2. Run the development server
npm run dev

# 3. Build production bundle for deployment
npm run build
```

The development server runs locally at `http://127.0.0.1:5173/`.

## 🌐 Deploy to Vercel

1. Import the repository from GitHub: [https://github.com/chowdhurybahalulhossain/portfolio](https://github.com/chowdhurybahalulhossain/portfolio)
2. Vercel automatically detects the Vite configuration:
   - Framework: `Vite`
   - Build Command: `npm run build`
   - Output Directory: `dist`
3. Click **Deploy**.
